## Limitations supported by the results

- One chronological test block (2026-03-30 to 2026-09-21) with {'C': 968, 'M': 117, 'X': 5} flares; no other part of the solar cycle is tested.
- Base rate shift: in-flare rate 0.1581 (training) vs 0.0812 (test); validation thresholds are conservative on test (outputs/tests/forecast_bias).
- One training seed per experiment for the main network (seeds: {'E1': 1337, 'E2': 1337, 'E4': 1337}); training variation is not in the intervals, which resample test days only. Seed variation is measured only for the rise-phase ablation (3 seeds).
- Only the >= C1 threshold is a model head; M1 is evaluated through alerts; X-class counts are too small for statistics.
- Flare onsets are GOES start times; an Aditya-only system would detect onsets itself.
- Design choices were made while earlier runs' test scores were visible (02b_leakage_prevention.md, section 6); only sealed forecasts after the study are free of this.
- Calling C vs >= M 3 min after onset, the network's TSS minus the GOES-now rule's is 0.0304 [-0.0303, 0.1036] (outputs/tests/peak_nowcast).
